# 日常英语跟读 — 姐弟版

> 给姐姐（四年级）和弟弟（一年级）做的英语跟读打卡 App。
> 不是 AI 教科书味，是真实家庭的鸡飞狗跳。

## 这是啥

每天 30 句英语对话，包含：
- 妈妈喊起床
- 姐弟抢卫生间、抢遥控器
- 告状、合伙偷吃饼干、互相安慰
- 厨房学剥皮、超市挑黄瓜
- 看医生、洗澡、睡前一万个理由
- ……一共 **24 天 720 句**，循环使用。

每句话有：
- 真人感的英文（带 ugh / pleeease / shut up / I'm starving）
- 口语中文翻译（不是"你很烦"，是"你烦死了"）
- 情绪标签（妈妈累了/姐姐嘲笑/弟弟告状），驱动 TTS 表演

## 怎么用

1. 点"开始今日打卡"
2. App 自动播第一句（妈妈/姐姐/弟弟/爸爸不同声音）
3. 点中文遮罩可以看翻译
4. 按住麦克风跟读
5. 评分 ≥ 75 分 + 词数 ≥ 70% → 自动下一句
6. 失败 3 次自动跳过（不让孩子卡死哭）

## 技术栈

- 前端：纯 HTML/JS，部署在 GitHub Pages
- 语音：OpenAI `gpt-4o-mini-tts`（中转走 Cloudflare Worker，保护 API key）
- 识别：浏览器自带 Web Speech API
- 评分：词级 + 字符级 Levenshtein 混合算法
- 数据：本地 localStorage 存连续天数和今日进度

## 成本估算

按 2 个孩子每天各跟读 50 句、每句平均 30 字符算：
- 每月 TTS 用量约 9 万字符 ≈ $0.09 ≈ **¥0.7/月**
- 加上 OpenAI 起充值 $5，能用半年以上

## 不懂代码也能改

- **加新对话**：打开 `data/daily-life.js`，照着第 24 天的格式往下加
- **改情绪**：emotionMap 里改英文 instructions
- **改颜色**：`css/style.css` 顶部的 #FF6B9D 之类换成你喜欢的
- **改密码**：先改 Cloudflare Worker 的 APP_PASSWORD，再改 App 设置里的密码
